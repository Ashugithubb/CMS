# 🎓 University Dashboard Web App

The **University Dashboard Web App** is a simple and interactive web application that displays a table of universities with features like **in-header filtering**, **sorting**, and a **styled tabular interface**.
Users can easily filter university data based on the type (e.g., Public, Private, Deemed) directly from the table header for a smooth and dynamic experience.

## 🖥️ Features

* 🔍 **In-Header Filtering** – Click on the **“Type”** column header to display a dropdown and filter table data instantly.
* 📊 **Tabular View** – Displays essential university details including:

  * Logo
  * Name
  * Type
  * Establishment Year
  * Country
  * Contact Information
  * Number of Students
* 🎨 **Styled Interface** – Responsive layout with modern CSS for an engaging and clean UI.
* ⚙️ **Dynamic Functionality** – Implemented using JavaScript for real-time DOM updates and filtering without page reloads.

---

## 🧰 Tech Stack

* **HTML5** – Structure of the web app
* **CSS3** – Styling and responsive design
* **JavaScript (Vanilla JS)** – Interactivity and filtering logic
